# AgriLearn chatbot (prototype)

Scripted sample by [92 Logics](https://www.92logics.com) for the Ethiopian Agricultural Transformation Institute AgriLearn chatbot (ATI-NCB-C-0022-2019-BID). It is not an official ATI system and not a bid.

Live page: https://92logics.github.io/ati-agrilearn-chatbot/

## What it shows

A learner-facing chat. Replies are limited to the public AgriLearn site (courses, enrollment, certificates, offline lessons, and the published support contacts). Unknown questions are refused instead of guessed.

Notice: https://production.egp.gov.et/egp/bids/all/tendering/c782adcd-cdec-411e-985a-cd9a8411bffe/open

## Run it

Open `index.html` in a browser. No install and no build step.
